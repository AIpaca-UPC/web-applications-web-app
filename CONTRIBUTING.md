# Guía de contribución — Rumbo Web Application

## Flujo de trabajo

1. Actualizar `develop`.
2. Crear `feature/<bounded-context>-<funcionalidad>` o `feature/<funcionalidad>`.
3. Implementar cambios pequeños y verificables.
4. Usar Conventional Commits.
5. Abrir Pull Request hacia `develop`.

## Ejemplos

- `feat(iam): add sign-in view`
- `feat(routes): add trip status view`
- `feat(shared): add language switcher`
- `fix(navigation): correct mobile menu`
- `refactor(routes): separate route service`

Los nombres definitivos de bounded contexts deben coincidir con los artefactos DDD aprobados en el Project Report.
