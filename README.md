# Rumbo — Frontend Web Application

Repositorio de la **Frontend Web Application** de Rumbo para el curso **1ASI0730 Aplicaciones Web**.

El Final Project Statement exige que el equipo declare el URL de este repositorio en **Source Code Management** desde AV1. La primera versión desplegada de la Frontend Web Application corresponde a una entrega posterior, por lo que en AV1 no se agrega estructura de implementación innecesaria.

Tecnologías definidas para el curso: **Vue Framework, JavaScript y PrimeVue**.
